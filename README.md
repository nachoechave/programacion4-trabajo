# Digital Custody

Aplicación web académica para registrar casos de análisis informático, administrar evidencias digitales y mantener una cadena de custodia trazable.

## Tecnologías

- Ruby 3.2.3
- Ruby on Rails 8.1.3.1
- PostgreSQL 16
- Active Record
- ERB
- Minitest

El desarrollo se realiza en Ubuntu 24.04 mediante WSL 2.
